Caption style

Premiere does not let panels set caption fonts, so the style is applied once per project: select the new caption track › Essential Graphics › set the values above › Track Style › Create Style… › name it "Basic (UGC) non background". After that, every new caption track: pick it in Track Style (one click).

Caption rules
Learning

Fix captions in Premiere, then select the caption track › File › Export › Captions… (.srt) and press Learn. Every word you corrected is applied automatically from then on. OMNI and OMNI Creatine Gummies are always capitalised.
